# Contributing

Feedback, implementation reports, and reproducible validation issues are
welcome through GitHub Issues.

When reporting a problem, please include:

1. the affected extension or example file;
2. the smallest CityJSON instance that reproduces the problem;
3. the validation command and tool version;
4. whether the issue concerns schema structure, CityGML mapping, reference
   resolution, an external resource, or application behaviour.

Pull requests should keep the examples valid and update documentation when a
public encoding rule changes.
